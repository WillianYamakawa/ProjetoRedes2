Prática – instalação, configuração e uso de servidores SMTP e POP3 

1. Procedimentos preliminares (Debian): configure a interface de rede

2. Instalação e teste do SMTP server

Instalação do SMTP server (no Debian):
apt-get install exim4

Para configurar a autorização para acesso aos clientes da rede local:
nano /etc/exim4/update-exim4.conf.conf
Altere as linhas (exemplos):
dc_eximconfig_configtype='internet'
dc_local_interfaces=''
dc_relay_domains='exemplo.com.br'
dc_relay_nets='127.0.0.1 : 192.168.0.0/24'

Atualize as configurações:
update-exim4.conf

Reinicie o serviço:
service exim4 stop
service exim4 start

debian:~# cat /var/mail/user


3. Instalação e teste de um POP3 server:

Instalação do POP3 server (no mesmo servidor do SMTP):
apt-get install dovecot-pop3d

nano /etc/dovecot/conf.d/10-auth.conf
Habilite temporariamente a interação sem criptografia, localizando e descomentando a linha:
auth_allow_cleartext = yes

Reinicie o serviço:
service dovecot stop
service dovecot start
